# 项目简介

这是一个基于 **Vue 3 + Vite** 的前端应用项目，使用 `vue-router` 进行页面路由管理，使用 `axios` 和 `vue-axios` 处理接口请求，部分页面结合 `echarts` 展示图表数据。整体界面偏向工具型后台，入口清晰、功能模块分区明确，适合在移动端或桌面端快速操作。

## 界面说明

### 1. 登录页
- 采用居中卡片布局，视觉焦点集中在用户名、密码和登录按钮上。
- 支持账号密码登录，并提供多服务地址切换，便于在不同环境间快速切换。
- 登录状态会自动检查，已登录用户可直接跳转到主页面。
- 登录失败时会弹出提示，输入区域简洁，适合移动端操作。
- 页面底部保留了一个独立的“随机数”入口，作为辅助页面单独打开。

### 2. 首页 / 功能菜单页
- 登录后进入功能入口页，整体为浅色背景 + 卡片式容器，结构清晰。
- 主功能以宫格按钮展示，每个入口都由图标和文字组成，识别成本低。
- 按钮按角色权限动态显示，不同账号看到的模块范围不同。
- 当前页面强调“快速进入”，适合作为整个系统的操作中心。
- 提供退出按钮，用于清理本地登录信息并返回登录页。

### 3. 视频管理页
- 页面顶部提供分类筛选和刷新入口，支持按路径过滤视频列表。
- 列表区域采用卡片式展示，每条记录包含名称、时长、缩略图和基础操作。
- 点击条目后进入详情视图，可查看视频名称、路径、时间、地址和标签信息。
- 详情页内置视频播放器，支持直接播放、刷新资源、旋转画面和分级标记。
- 支持“不喜欢”、“top1~top4”、“best”等快捷标记，适合做内容筛选与整理。
- 支持“官网”跳转和继续加载更多数据，适合批量浏览和逐条处理。
- 页面底部和列表页都保留分页/加载入口，方便连续翻阅。

### 4. 其他业务页面
- 金价 / 新金价：用于展示贵金属相关数据或趋势信息。
- 房价 / 二手房 / 成交：用于房产相关数据查看与分析。
- 地址 / 收藏 / 采集 / 自动化：用于常用数据管理和日常操作。
- 房贷计算器：用于快速计算贷款信息，属于高频实用工具页。
- 二维码、打卡、人员记录等页面：用于辅助业务和流程类操作。
- `r.html`：一个独立的随机点数页面，点击主区域即可随机生成区间内数字，底部可调整最小值和最大值，刷新时会切换背景色并播放提示音，适合做抽签、随机选择或演示用途。
- 各页面均通过路由独立组织，入口统一，便于后续扩展维护。

## 主要功能

- 登录 / 首页入口
- 视频与内容展示页面
- 金融相关工具页
- 二维码、采集、自动化与业务列表页面
- 房贷计算等实用工具页面
